# dram/ parameters and their sources

Every value the DRAM/PIM side uses or produces, with its source. Each row was checked twice against the primary source
(paper page, standard table, upstream code at a pinned commit, or our measurement files). Derived values were
recomputed, and simulator settings were rerun where the note says so.

- **Status.** *verified*: value and unit match the source; derived values recompute. *verified, note*: confirmed, with
  a caveat in the last column. *assumption*: no direct source; the last column gives the reason and, where it exists,
  the effect.
- **Sources.** Papers by section, page, table or figure. JESD238B.01 by section and table only. Upstream code at
  pinned commits: AttAcc simulator [c600051](https://github.com/scale-snu/attacc_simulator/tree/c60005143a6b492d7ef83231723386478b59a506),
  Ramulator 2 [b7c7027](https://github.com/CMU-SAFARI/ramulator2/tree/b7c70275f04126c647edb989270cc429776955d1),
  DRAMsim3 [2981759](https://github.com/umd-memsys/DRAMsim3/tree/29817593b3389f1337235d63cac515024ab8fd6e),
  HBM-Power v0.3-alpha [4642c61](https://github.com/CMU-SAFARI/HBM-Power/tree/4642c61f856cbd9d5d3f37d56214e5dbfa663703)
  and main [61aada9](https://github.com/CMU-SAFARI/HBM-Power/tree/61aada9a54ec349efde024b77f868b1a7ebeba0e).
  Paths in backticks are in this repository. *Measurement repo* is our private measurement repository at commit
  38e0926; *analysis repo* is our analysis repository. Values from either are copied into `dram/data/` or
  `thermal/data/` where the model uses them.
- **Paper short names.** AttAcc = Park et al., ASPLOS 2024. HBM-Power = Olgun et al., MICRO 2026 (arXiv:2610.14244).
  HBM-PIM = Lee et al., ISCA 2021. FGDRAM = O'Connor et al., MICRO 2017. NeuPIMs = Heo et al., ASPLOS 2024.
  Mukundan = Mukundan et al., ISCA 2013. LLaMA = Touvron et al., arXiv:2302.13971. Llama 3 = arXiv:2407.21783.
